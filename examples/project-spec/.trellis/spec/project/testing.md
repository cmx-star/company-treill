## 变更与验证

| 变更类型 | 最小验证 |
| --- | --- |
| 纯文档 | 链接、示例和格式检查 |
| 局部逻辑 | 相关单元测试和静态检查 |
| 跨模块行为 | 单元测试、集成测试和数据流检查 |
| 公共契约 | 兼容性测试、类型检查和调用方验证 |
| 用户界面 | 组件测试及关键用户流程验证 |
| 数据迁移 | 正向迁移、失败恢复和回滚验证 |

## 回归测试

- Bug 可稳定复现时，新增修复前失败、修复后通过的测试。
- 测试应覆盖触发条件和失败路径，不能只重复实现逻辑。
- 无法自动化时，记录手动步骤、实际结果和未覆盖风险。

## 完成标准

- 测试范围与改动风险相匹配。
- 失败路径和兼容性要求得到覆盖。
- 报告的是本次实际运行结果，不沿用历史测试结论。
