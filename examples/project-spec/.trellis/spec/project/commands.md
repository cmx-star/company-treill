## 使用规则

- 优先运行受影响包或模块的定向命令。
- 修改共享模块或公共契约时，再运行全量检查。
- 无法运行命令时记录原因、环境限制和潜在风险。
- 不在本页记录真实凭据、内部令牌或个人绝对路径。
