# 项目规范索引示例

> 本目录是编写示例，不是可以直接发布的项目规范。使用时应根据目标项目的代码、配置、脚本和 CI 重写内容。

## 项目规范负责什么

项目规范只记录当前项目特有且能够验证的事实：

- 架构边界和模块职责。
- 技术栈及项目内约定。
- 标准开发、构建和验证命令。
- 测试分层和验收要求。
- 业务契约、兼容范围和敏感区域。

公司通用 Workflow、Git 流程、安全和质量底线不在这里复制。

## 文档入口

| 文档 | 内容 |

| [architecture.md](architecture.md) | 架构、模块边界、数据流和公共契约 |

| [testing.md](testing.md) | 测试分层、最小验证和高风险检查 |

## 编写检查

- 每条规则都能指向代码、配置、脚本、CI 或明确决策。
- 不写与当前项目无关的通用最佳实践。
- 不记录密钥、内部账号、客户数据和个人环境路径。
- 命令经过实际运行或明确标注为未验证。
- 规则失效时随代码变更同步更新。
